CSV File Format Instructions

Upload a CSV or Excel (.xlsx) file with the following columns (in order):

  1. Resident ID - Unique identifier for the resident
  2. First Name - First name of the resident
  3. Last Name - Last name of the resident
  4. Middle Initial - Middle initial (optional)
  5. Age - Age in years (number)
  6. Purok - Purok number or name
  7. Contact - Phone number
  8. Gender - Male/Female/Other
  9. Civil Status - Single/Married/Widowed/Divorced
  10. Occupation - Job or profession

Note: The first row should be headers and will be skipped during import.
